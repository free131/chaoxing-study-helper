# 学习通学习助手

适用于超星学习通的 Tampermonkey 用户脚本，支持 **题库海查询、DeepSeek AI 补答、暂停与继续、音视频播放和自动切章**。

[安装脚本](https://raw.githubusercontent.com/free131/chaoxing-study-helper/main/chaoxing-deepseek.user.js) · [查看源码](./chaoxing-deepseek.user.js) · [反馈问题](https://github.com/free131/chaoxing-study-helper/issues)

> **费用说明**：脚本本身不收费，也不提供免费题库。DeepSeek 与题库海的账号、密钥及服务费用由使用者自行管理，相关收费与本项目无关。

## 功能

| 功能 | 说明 |
| --- | --- |
| 题库优先，AI 补充 | 每题先查题库海，没有可用答案时调用 DeepSeek；下一题重新从题库查询开始 |
| 三种查询模式 | 可选择题库优先、仅题库或仅 DeepSeek |
| 文字题填答 | 支持已适配页面中的单选、多选、判断、填空和简答题 |
| 手动开始 | 首次进入或手动刷新页面后，点击“开始作答”才运行 |
| 暂停与继续 | 面板按钮或 `Alt + P` 控制；面板收起后也可操作 |
| 自动切题 | 统一控制作业、章节测验和考试的连续答题 |
| 音视频与切章 | 支持音视频播放；本章任务被平台标记完成后可自动进入下一章 |
| 题库海次数 | 显示最近一次查询返回的已用次数与剩余次数 |
| 密钥查看 | 已保存密钥默认显示黑点，点击眼睛按钮查看或隐藏 |

脚本在 `https://*.chaoxing.com/*` 范围内匹配，实际功能在已适配的课程、作业、章节测验和考试页面启动。不同课程页面可能存在差异，不保证所有页面均可使用。

## 安装

1. 在浏览器中安装并启用 **Tampermonkey（油猴）** 扩展，允许其运行用户脚本。
2. 点击上方的 **[安装脚本](https://raw.githubusercontent.com/free131/chaoxing-study-helper/main/chaoxing-deepseek.user.js)**，在油猴安装页面确认安装。
3. 如果链接只显示源码，在油猴中新建脚本，将源码全文复制进去并保存。
4. 打开学习通的课程、作业或测验页面，刷新后查看“学习助手”面板。

同一浏览器中只启用一份本脚本，避免多个版本同时处理题目。

## 首次使用

1. 打开面板的 **参数设置**。
2. 在“答案来源与密钥”中选择查询方式，并填写所需密钥。
3. 检查自动切题、章节自动提交和自动切章等开关，点击 **保存设置**。
4. 返回当前任务，点击 **开始作答**。

| 查询方式 | 配置要求与行为 |
| --- | --- |
| 题库优先，AI 补充（默认） | 启用题库海，配置题库海密钥及 DeepSeek API Key；每题先查题库，无可用答案再用 AI |
| 仅第三方题库 | 启用题库海并配置其密钥；不调用 DeepSeek |
| 仅 DeepSeek | 配置 DeepSeek API Key；不查询题库海 |

题库海密钥只发送给题库海，DeepSeek API Key 只发送给 DeepSeek。AI 补答只影响当前题目，不会把后续题目永久切换为 AI 模式。

### 密钥的保存与查看

- 已保存的密钥默认用黑点表示；点击输入框右侧的眼睛按钮查看，再次点击隐藏。
- 输入新值后点击“保存设置”可更换密钥；留空保留原值。
- 要清除密钥，请使用对应的“删除已保存密钥”按钮。
- 保存、收起面板、离开设置或页面切到后台时，会重新隐藏密钥。

## 参数设置

### 答题与章节控制

| 选项 | 作用 |
| --- | --- |
| 自动答题 | 点击开始后，自动查询并填写答案 |
| 自动切题 | 开启后连续处理题目；关闭后，同页每题处理完成会暂停，点击“继续作答”处理下一题；考试分页需手动切换 |
| 答题间隔 | 题目处理及考试切题的等待时间，单位为秒 |
| 章节自动提交 | 仅用于章节测验；作业和考试仍由使用者手动提交 |
| 最低填答率 | 达到此填写比例后才允许章节自动提交；`0.8` 表示 80% |
| 自动切章 | 当前章节任务被平台标记完成后，自动进入下一章 |
| 切章间隔 | 切换章节前的等待时间，单位为秒 |

**最低填答率是填写成功的比例，不是答案正确率。** 自动切题、章节提交和自动切章各自独立，开启自动切题并不等于开启自动提交。

全新安装默认开启自动答题、自动切题、音视频自动播放及自动切章，关闭章节自动提交。旧版本升级会迁移已有开关值，请在使用前核对设置。

### 答案来源与密钥

设置查询方式、题库海开关，以及题库海和 DeepSeek 密钥。默认模式为“题库优先，AI 补充”。

### 音视频

控制音视频自动播放。脚本不强制设置倍速；浏览器阻止自动播放时，需要手动点击一次课程播放器。

### AI 高级参数

默认折叠，可修改模型名称、深度思考开关和超时时间。脚本当前预设为 `deepseek-flash`、关闭深度思考、超时 120 秒；模型名称需要与你的 API 服务实际支持的模型一致。

## 开始、暂停和切章

- 每次新开或手动刷新页面，都需要先点击 **开始作答**。快捷键不能代替首次点击。
- 点击 **暂停作答**，或按 `Alt + P`，停止后续查询、填写、提交和切换操作，并暂停脚本正在管理的音视频。
- 已经发出的请求可能继续返回；继续后可复用结果。暂停不能撤回已提交的内容，也不能保证取消已经产生的 API 费用。
- 暂停状态在脚本标签页之间同步，并在刷新后保留；刷新仍需要重新点击开始。
- 脚本自动切换章节后会继续运行，无需再次点击开始。章节任务未完成、提交条件未满足或遇到需手动处理的任务时，会停留等待。

## 常见问题

**油猴提示匹配了网站，但没有面板？**

确认扩展和脚本均已启用，浏览器允许用户脚本运行，并刷新已适配的课程、作业或测验页面。域名匹配并不表示网站的每个页面都会显示面板。

**有面板但没有开始答题？**

先点击“开始作答”，并检查“自动答题”是否开启、当前是否暂停，以及所选模式的密钥是否配置正确。错误详情可查看运行日志。

**答完一道就停了？**

检查“自动切题”是否开启。关闭时，同页题目需要点击“继续作答”逐题处理。

**题库海次数为什么显示“未获取”？**

次数来自最近一次查询响应。尚未查询、只使用 DeepSeek，或题库没有返回次数字段时，会显示“未获取”。剩余次数为零时显示 `0`，不会显示为无限。脚本不会用本地请求次数推算服务商扣费。

**为什么没有自动进入下一章？**

检查“自动切章”开关和当前任务是否被平台标记完成。章节测验未提交、填答率不足、页面加载异常或未知任务类型，都可能需要手动处理。

**图片题或某些题目没有答案？**

当前主要处理文字题。图片题、未支持的题型、字体解析失败以及答案格式无法匹配的题目，会跳过或提示错误，需要手动检查。

## 数据与隐私

运行时，启用的服务商会收到用于查询的题干、选项、题型等必要内容。脚本使用以下固定 HTTPS 接口：

| 服务 | 接口 |
| --- | --- |
| DeepSeek | `https://api.deepseek.com/chat/completions` |
| 题库海 | `https://api.tikuhai.com/search` |

密钥保存在油猴存储中，不写入脚本源码或运行日志。脚本不主动附带课程 URL、UID 或 Cookie，不跟随题库返回的地址抓取页面，也不额外上传已完成题目。请求设置了超时、取消及重定向限制。

密钥遮罩和面板隔离不能抵御被攻陷的浏览器或恶意扩展。不要在反馈问题时附上密钥、Cookie，或带个人身份与签名参数的完整课程链接。

## 更新与反馈

当前安装版本为 **1.0.0**。脚本未配置自动更新源，更新时请重新安装最新文件，或在油猴编辑器中全文替换后保存、刷新页面。

提交 [Issue](https://github.com/free131/chaoxing-study-helper/issues) 时，建议附上：

- 浏览器、油猴和脚本版本；
- 页面类型（课程、作业、章节测验或考试）；
- 问题现象、复现步骤和已脱敏的日志或截图。

本仓库当前提供可直接安装的独立脚本，无需构建。答案由外部服务提供，请自行核对；平台页面与服务接口变化也可能影响可用性。
